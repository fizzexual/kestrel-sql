This is a standalone model, configuration rejected. It is not a SQL engine, catalog migration or production format. Supported 0.3.16 remains unchanged; its reader does not accept `KCMP0701`.

1. Extract the private immutable evidence ZIP into a fresh trial directory. Preserve original policy, failures and raw cases. Use the recorded Rust 1.97.1/Python 3.12.10 environment. Model Cargo.toml/Cargo.lock and every pinned registry crate archive are included. Install exactly Apache Arrow (pyarrow) 25.0.1 for the independent byte oracle; original binding/DLL hashes and paths are recorded, but its binary distribution is not included in this ZIP.
2. Inputs are the same actual retained generation-129 CAT4 checkpoints from 068/069, containing 126/50,126/99,126 receipts and 21,904/8,222,890/16,271,376 bytes. Provenance verifies the checkpoint envelope CRC, JSON type, receipt count and SHA-256. No database workload recreates the input.
3. Run locked offline model qualification serially before timers. Twelve native tests pass in debug/release, format and strict Clippy pass. The linked library is checked as Zstandard 1.5.7; safe wrapper 7.2.4 uses default features disabled plus std. The initial API type-check build failure and source are retained. The three Python boundary test groups passed before timing.
4. Declare a new independent policy and remap absolute paths for reproduction. Four rotated rounds x three sizes x raw A/raw B/Zstandard C = 36 serial cases, twelve publications and twelve fresh-open checks each. One frozen executable and raw input path/mode serve both A/B labels. Original thresholds and accounting are identical to 069. Freeze model, harness, oracle, input and policy hashes before first timing.
5. Level 1 one-shot compression creates its context per publication; context, buffer allocations, checksum/frame copies and release are charged. Both modes use create_new/write/flush, one sync_all, close and rename. Canonical input read and exact comparison are excluded. No dictionary, workers or context reuse. All stored payloads have a 64 MiB bound; native decoding checks exact standard single-frame consumption and known content size before allocating the bounded output. Native tests cover malformed, concatenated, skippable, unknown-size and corrupt frames.
6. Run one task-owned child at a time on this computer. Do not compile, test, audit, package or run Git during timed workloads. Preserve every completed, failed or timed-out case and every frame; never rerun a case to replace a stall. The disk guard is 3 GB free, per-case timeout 600 seconds. Memory is full-process peak working set/commit, including setup and validation.
7. After every child exits, audit all 432 frames. A separate Python parser checks exact frame boundaries, size and block limits; Arrow's separate binding decodes each payload and compares exact original bytes, with all outer CRCs. Arrow may share the upstream codec implementation; it is not an independently implemented codec. The auditor computes Type7 quantiles over twelve samples and medians of four matched ratios, retaining every round and applying all 47 original checks.

Fresh-open read/decode runs in the same process after writes with potentially warm OS caches. It is not cold Archive reopen. SQL, serde, source offsets, growing receipts, old-format migration, Archive retries/crash behavior, concurrent readers, compaction, service traffic and physical power-loss behavior are outside this model. Existing SQL/recovery evidence is separate. No engine source/dependency, supported binary, morning report or prior benchmark has changed. English only; this computer only; no deployment or messages to others.
