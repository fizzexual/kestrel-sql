# 0.3.15: bounded reuse of independent scan handles

**The 0.3.15 bounded reader reuse experiment.** Each segment can retain one exclusively owned idle stream file, with a shared limit of 128 idle files per archive. Queries still read and validate payload checksums; full scrubs open fresh files. In 21 alternating 1M-row fragmented scan pairs, the unordered query changed from 7.830 to 4.551 ms (paired ratio 0.581); 1,000-row sparse SUM changed from 0.118 to 0.065 ms (paired ratio 0.560). Fresh DuckDB scores are 59 wins/1 loss over 60 shapes. PERFORMANCE_045.md retains every slower guard, the unselected offset-only trial, 76 Rust tests, 4,000 SQL checks against each reference, 104 concurrent/manual bridge oracles and current retry/crash/Parquet evidence.
