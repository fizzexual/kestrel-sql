# KestrelSQL 0.3.6: reusable immutable embedded batches

The 0.3.6 immutable batch experiment adds `PreparedBatch` and `LiveArchive::append_prepared` for confirmed embedded retries. Its extra receipt index stays off by default; construction and fresh-write costs remain disclosed. Previous packages and measurements are preserved.

[Archived complete report](https://github.com/fizzexual/kestrel-sql/blob/bb25f1547be393a6e6607a4ce54cf179abb85666/PERFORMANCE_036.md). Current release status: [version summary](VERSION_SUMMARY.md). Completed local run artifacts follow the storage policy.
